# 风格：贴纸科普（sticker-explainer）

回形针式的知识解说：冷灰点阵大画布上铺满粗白描边的扁平图标"贴纸"，镜头在画布上平移缩放，把一个个信息点串起来。适合讲流程、原理、"一件事背后发生了什么"。横屏 16:9。

示例 `example/` 是《按下回车之后的 1 秒》：浏览器从输入网址到画出页面的 6 步，60 秒无配音，加旁白后 67.5 秒。新片从它复制开始，换内容，不换骨架。

## 视觉规范

| 项 | 取值 |
|---|---|
| 底色 | `#E9EEF2`，60 px 点阵 `#C8D2DB`（画在世界坐标里，镜头一动点阵跟着动，有速度感） |
| 主色 | 深石板 `#263646`（文字、图标）、中灰 `#5E6E7E`（说明）、浅灰 `#D6DFE7`/`#B7C3CE`（线） |
| 强调 | 橙 `#FF5A36`（客户端、重点、章节号），蓝 `#3D6FE0`（服务端、回应）。一个画面最多这两种强调色 |
| 字体 | 中文 Noto Sans SC，英文 Inter，代码和数字 JetBrains Mono（都是 OFL） |
| 贴纸 | SVG 滤镜 `#stk`：9 px 白描边 + 柔和投影。所有图标都是代码画的，不用图片 |
| 字号 | 1080p 下正文不小于 26 px（世界坐标乘以镜头缩放后）；章节标题 62 px；抖音推荐流里横屏只占屏幕一条，宁大勿小 |
| 安全区 | 四周留 5%（左右 96 px、上下 54 px）；底部 960–1040 px 留给字幕 |

## 结构骨架

| 段落 | 示例里的时间 | 做什么 |
|---|---|---|
| 钩子 | 0–4 秒 | 主角道具砸下（回车键），片名两下砸出，第一帧就有东西，不黑场 |
| 章节 × N | 每章 6–10 秒 | 章节标签（橙色编号圆 + 标题 + 记号笔下划线）→ 两端角色（你的电脑 / 服务器）→ 消息箭头带标签往返 → 结论 |
| 总览 | 约 4 秒 | 镜头拉远看全程，章节标签放大成"地铁站"，数据包沿线路跑一遍 |
| 高潮 | 约 60–85% 处 | 按比例的数据图（耗时条扫过），关键数字砸下前配乐抽空 3 帧 |
| 结尾 | 约 5 秒 | 一句话结论 + 账号落款（`brand.name`）+ 角色贴纸（`brand.mascot`） |

右上角常驻进度胶囊（6 个章节点 + 当前章名 + 示例耗时累计）。

## 组件（都在 index.html 里）

- `sticker(parent, draw)`：贴纸容器，外层管位置动画，内层挂描边滤镜。
- `popper(g, x, y, t0, {rot, drop, from, out})`：弹入（outBack 回弹），可选淡出。
- `rise(textEl, t0, {out})`：文字淡入上移。
- `message(A, B, t0, t1, 标签, {color, keep, gloss, hold})`：箭头从 A 画到 B，标签压在线上跟着箭头走；`keep` 到达后停在线中点，`gloss` 是线下方的中文解释，`hold` 控制不保留的标签停到何时。
- `pair(lx, rx, y, t0, lifeEnd)`：两端角色加虚线生命线（时序图）。
- 章节标签、地铁线路、数据包、HUD、字幕层、耗时条都是成段的代码，复制改数据即可。

## 镜头

关键帧 `k(t, x, y, z, fly)`：停留段线性慢推（z 每段 +2% 左右），飞行段用 inOutQuint 平移、缩放走对数插值、途中略拉远。下一章的基础元素在飞行进行到 42% 时开始弹出（`arrive(fly)`），镜头落地时画面已有东西。

## 配乐

mgaudio 的 `explainer` 配方（马林巴科技解说床，112 bpm 左右，D 大调）。音效：章节弹出 pop + 记号笔、消息出发 swish 到达 blip（音高跟和弦走）、印章 stamp、贴纸 sticker_slap、高潮 riser + impact + boom，砸下前配乐和音效一起抽空 3 帧。说话处配乐压低 8 dB。
