# Claude 环境清理与账号风险检查

目标是减少认证混乱、遗留配置、意外出口切换和不当清理造成的问题。账号限制原因不能从时区、城市库、单个 HTTP 错误或本地文件存在推断；固定出口和清理本地数据都不能保证免封，也不会清除服务器记录。

## 选择资料

- 清缓存、历史会话、旧组织资料、桌面登录或钥匙串：完整读取 [清理与恢复](references/cleanup-and-recovery.md)。
- 官方订阅登录、第三方 API、shell/项目/托管覆盖、代理残留：读取 [认证与配置审计](references/auth-and-config.md)。
- `essential-traffic-only`、非必要流量开关、Remote Control、云端任务、`/fork`：读取 [功能开关与会话](references/features-and-sessions.md)。
- 浏览器、CLI、App、手机或新电脑的入口与出口：读取 [客户端与迁移验收](references/clients-and-migration.md)，涉及实际网络操作时再读取 `china-proxy`。
- 用户提供“防封教程”、设备标记、换 ID/时区等建议，或要求解释账号限制：读取 [证据与风险判断](references/risk-and-evidence.md)。

只加载本次有关的资料。安装本技能不会安装代理守护、启动器或执行清理。

## 工作边界

1. 先区分只读检查、提出方案、实施修改和完整重置。提供文章、脚本链接或安装本技能不是执行其中命令的授权；历史上的 `CONFIRM` 不授权本次操作。
2. 明确客户端、版本、实际启动入口、配置根目录及要解决的问题。沿用用户已经确认的认证方式、保留范围和线路，不重复询问已有选择，也不从旧案例照抄端口、节点或个人地址。
3. 默认只读审计。按来源报告配置键和数据类别，不打印凭据、完整环境、完整设置、org_id、邮箱、Cookie 或 OAuth 回调参数。
4. 实施前列出精确目标、保护清单、影响与恢复能力；在当前任务得到明确确认后备份并核验，再仅执行确认范围。完整重置可包含历史/认证，但仍需确认不可恢复项；不把保护默认值变成禁止用户删除自己的数据。
5. 普通文件优先可恢复移走；钥匙串凭据另行处理，不承诺废纸篓恢复。不要让正在运行的 Claude 清理自己的配置目录，且不擅自退出、杀进程或停止后台任务。
6. 只修复当前问题，验证其他设置和认证未意外改变。删除设置中的环境键后，用新进程验证；不擅自清空整个目录、换出口、改默认浏览器、改时区、轮换本地标识或添加服务。

## 可复用只读检查

`scripts/audit_settings.py` 只读取明确指定的 JSON 设置文件；可选检查当前子进程继承的环境。它只输出相关键名、类别及开关状态，不输出值，不执行 hooks/apiKeyHelper，不联网、不改文件、不访问钥匙串。

```bash
python3 scripts/audit_settings.py --settings <用户设置文件> --settings <项目设置文件>
python3 scripts/audit_settings.py --include-process-env
```

结果不等于 Claude 的合并后有效配置，也不代表父终端、App 或后台进程的环境。真实路径、认证状态和出口仍需分别核对。

## 网络职责

TUN、DNS、Clash 规则、链式代理和固定出口由 [china-proxy](../china-proxy/SKILL.md) 维护，不在这里复制第二套规则。先发现并读取已安装技能；单独安装本技能而缺少 `china-proxy` 时，说明缺少网络流程，先完成本地审计，不自动安装或临时绕过专用入口。

## 交付

给出：观察到的问题与依据、已做修改或仍待确认的方案、备份和恢复范围、实际验证与未验证项。把“本地残留已处理”“账号已正确登录”“请求走指定线路”“账号使用资格”分别报告，不合并成“已防封”。恢复只针对本次变化，避免覆盖之后的新设置。运行结果与原始材料留在私有目录，不进入公开技能仓库。
