# 医荟她健康文章样式

目标账号的默认输出画像，来自用户最喜欢的已发布 HPV 长文。原始 HTML 和科学图留在私有目录，仓库只保存提炼出的参数。光愈在线是设计参考来源之一，不是发布主体。

## 字体与空间

| 元素 | 默认值 |
|---|---|
| 正文 | 15px；line-height: 1.8；letter-spacing: 1px；颜色 #3E3E3E |
| 导语 | 15px；line-height: 1.8；letter-spacing: 0.5px |
| 主视觉章节标题 | 18px |
| 章节数字（使用时） | 21px |
| 引文序号 | 11px |
| 参考文献 | 12px |
| 桌面样本内容区域 | 宽 677px，padding: 24px 18px 40px |
| 科学图间距 | 样本 margin: 30px 0 36px，按移动端观感复核 |

样本根容器继承 16px，但实际正文块为 15px。检查实际正文的计算样式，不能只读父容器。

宽度使用自适应布局；677px 是桌面样本测量条件，不是手机最小宽度。科学图不超过内部可用宽度，样本实际约 625px。在手机宽度复核无横向溢出、图中文字可辨认。字号落地配置见 [yihui.css](../../assets/themes/yihui.css)，通过苍何原生外部主题接口加载。

## 已验证的苍何调用方式

审计版本 `dd0bf355955b4c82b764740b4183c86a72ba0e0c` 的渲染器原生支持 `MD_THEME_DIR`，无需修改或复制上游。该主题是品牌参数配置，不是另一套渲染器，也不声称完整复刻编号标题卡。

安装渲染器 `scripts/md/package.json` 中的依赖后，将正文 Markdown 的工作副本交给其自带 `scripts/md/render.ts`。工作副本不带 YAML frontmatter；标题/作者/摘要另传给发布器。首个 H1 仅作文章标题，由默认行为移除；不要把首个正文小标题当作文章标题。正文没有文章标题时使用上游 `--keep-title` 保留第一个章节。

```bash
MD_THEME_DIR="$MEDICAL_SKILL_DIR/assets/themes" \
  bun "$CANGHE_HTML_SKILL_DIR/scripts/md/render.ts" \
  /path/to/article-body.md --theme yihui
```

两个目录变量必须先解析为实际安装目录。生成 HTML 与输入同目录，已有 HTML 由上游自动备份。图片使用真实本地路径（相对路径按文章目录解析），不要依赖占位符作为预览图片。

选择该入口的实测依据：

- 顶层 `scripts/main.ts` 会将图片写成 `MDTOHTMLIMGPH_*`，同时提供 `data-local-path`，发布器能识别，但直接浏览器预览不能显示。
- 带 frontmatter 的测试稿经顶层入口出现多余分隔线及残留 H1；当前版本的 CJK 预处理发生在 frontmatter 解析之前。
- 普通 Markdown 的直接渲染入口已验证两图正常显示、无重复 H1、正文 15px/27px/1px、导语字间距 0.5px、390px 手机宽度无横向溢出。
- 此版本原生脚注经过预处理的结果需逐项核对。医学编号参考文献可用已有编号正文和普通参考列表；需要 12px 时以 `yihui-references` 包裹引用列表。不能因转换丢失文献而交付。

这只是输出适配，不改变 Writer 原稿、研究方式或医学引用内容。升级上游后重新验证这些限制，不永久固化绕行。

## 标题与信息密度

默认少量大章节、连续论证、局部粗体强调，科学图穿插在证据解释处。基准文章用了三个主视觉标题，这不是所有文章必须三章的要求。

不要把每个问题或逻辑段都渲染成大型卡片。用户未指定组件时只用必要的导语、标题、正文、引用和结尾，不自动加入关注条、访谈气泡、马年 KV 或全部品牌组件。

## 科学图位置

按证据和论证单元选择插入点：图前解释为什么看图，图后解释关键含义，不逐字重复图内文字。两张高密度图之间通常保留一个完整论证单元。没有科学图需求的文章不强制配两张图。

基准文章两张图约在页面高度的 19.8% 和 55.8%，说明第二张图不必放到 60% 以后。百分比仅记录样本，随屏宽和文本变化，不作为验收阈值。调整位置时保留证据段、引用、前向提示和桥接句。

内容约束见 [medical-figure-design.md](../medical-figure-design.md)。图内已有完整 Caption 时，HTML 避免重复同一图注；来源仍须能回到参考文献。

## 交付验收

查看最终 HTML 与手机宽度预览，确认正文计算样式、连续阅读、图文衔接、图中文字和参考文献。正文不重复文章 H1。用户指定组件时核对 ID 及使用版本。

结合 [品牌画像](../brands/yihui-she-health.md) 检查医荟她归属、真实素材、2.35:1 封面与无光愈业务残留。视觉参考不能复制成医学结论。

这份画像验证风格，不验证医学事实，也不证明上传成功。正文事实按医学约束检查；真实草稿的图片、封面与排版按发布器结果检查。
