# 医荟她健康品牌运行画像

> 用途：这是 `wechat-medical-writer` 的**目标公众号品牌画像**。它定义最终输出应该属于谁、当前有哪些渠道能力，以及哪些参考品牌元素只能借鉴不能照搬。
>
> 目标公众号：**医荟她健康**。
>
> `光愈在线` 仅是参考公众号，不是最终发布品牌。

## 1. 品牌归属

所有面向实际发布的成品，默认归属：

```text
公众号：医荟她健康
```

因此最终输出中：

- 不得把 `光愈在线` 当作发布主体；
- 不得沿用 `光愈在线` 的 Logo、二维码、小程序名称、服务号名称、项目名称、责任编辑、审批号或品牌落款；
- 可以借鉴 `光愈在线` 的视觉语法、信息密度、图片尺寸策略、章节节奏、Figure 方式和封面色调；
- 如需要品牌名称文字，使用 `医荟她健康`；
- 如没有用户提供的正式 Logo / 二维码 / 品牌资产，宁可不放，也不得生成一个看似官方的替代品。

核心原则：

> **参考品牌决定“怎么呈现”，目标品牌决定“谁在说话”。**

## 2. 当前渠道能力

当前阶段：

```text
微信公众号：有
小程序：无
```

因此当前文章默认：

- 不插入小程序卡片；
- 不生成小程序二维码；
- 不写“点击进入小程序”“内容中心/直播中心/个人中心”等并不存在的产品入口；
- 不虚构 AppID、path、页面截图、功能模块或上线状态；
- 不因为参考文章里出现小程序，就把小程序组件照搬进 `医荟她健康`。

如果文章涉及未来规划，可以使用谨慎的未来式表述，例如“后续可考虑开发小程序”，但不能写成已经上线或已经可用。

## 3. 未来小程序启用条件

后续真正开发并上线小程序后，再启用相关组件。至少需要用户提供或确认：

```text
小程序正式名称
AppID
页面 path / 路由
真实二维码或微信生成素材
真实页面截图
当前已上线功能清单
```

只有在这些真实信息存在时，才可以增加：

```text
小程序卡片
小程序二维码
功能入口图
内容中心 / 直播中心 / 个人中心等模块说明
```

不能为了提前“预留能力”而在当前文章中出现空壳入口。

## 5. 公众号封面规则

医荟她健康公众号封面默认使用：

```text
宽高比：2.35:1
```

除非用户明确指定其他比例，公众号封面生成、裁切和最终检查都按 2.35:1 执行。

封面应优先服务文章主题与移动端缩略图识别，不为了“品牌感”强行塞入过多组件。若使用 Logo，必须来自上面的真实候选资产且版本已被用户明确选定；若没有明确主 Logo，可以只使用“医荟她健康”文字品牌而不强行放图形标识。

排版 / 图片 / 封面需要参考光愈在线时，同时读取：

```text

../layouts/guangyu-launch-first-article.md   # 首篇上线文章的图片化格式研究
```

使用方式：

```text
光愈在线        → 参考视觉、格式、图片尺寸、节奏
医荟她健康      → 最终品牌、文案主体、Logo、二维码、渠道能力
```

不得把两者混为一个品牌。
