# 公众号组件库外部接口

仅在用户指定样式 ID 或现有主题不能表达所需组件时读取。通用组件实现由 [image-gallery](https://github.com/sdwurg180507280211/image-gallery/) 的 `wechat/index.html` 维护；医学 Skill 不复制 HTML/CSS 引擎，也不维护第二份完整组件注册表。

## 选择与版本

用户指定如“标题-02 + 正文-02 + 参考文献-01”时，从实际组件源查找对应 ID，使用其可复制 inline HTML；不擅自换 ID 或增加大量未指定卡片。找不到组件时报告缺项，不生成一个同名的替代组件。

为复现当次输出，记录实际读取的 image-gallery commit（或离线快照的内容指纹）与所用 ID，可写在已有交付说明中，不强制新建文件。复做同一稿件时复用该版本；只有明确更新样式时才切换。运行时尚未解析固定版本前，不把“当前 main”称为锁定依赖。

图形界面与旧文档不一致时，实际读取版本的组件实现决定 HTML；用户明确偏好仍优先，不可静默覆盖。组件页面的站点导航、研究说明和 UI CSS 不进入文章。

未指定 ID 时使用 [医荟她默认样式](yihui-article-style.md) 的最小必要组合，不要求用户挑选全部组件。

## 品牌图片与通用组件分开

历史 ID `图片-01` ～ `图片-06` 是现有品牌资产别名，不是六种通用图片排版模板。具体文件名、候选 Logo 和马年 KV 的使用范围见 [医荟她品牌画像](../brands/yihui-she-health.md)。

不在本仓库擅自改外部 ID；使用时同时核对文件名和语义。马年 KV 只适用于相应内容，不作为每篇文章默认封面。

预览可以引用正式来源地址；发布时由现成发布器上传并检查微信草稿图片。禁止占位 URL 进入成稿。不得将原始第三方品牌素材或用户样稿复制入本仓库。

新增组件、注册表或版本机制应在 image-gallery 实现。本文件只维护消费规则，不宣称外部已经存在机器可读 JSON 接口。
