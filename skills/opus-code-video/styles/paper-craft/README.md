# 风格：纸艺立体（paper-craft）

科普系列的默认风格（2026-10-27 用户从三种样片里选定，对比见 `~/ideaProjects/ai-video-workbench/AI视频/代码动画/风格探索/风格对比.mp4`）。
所有东西都像彩纸剪出来贴在墙上：边缘有一点毛边，表面有纸纹，一层层叠着，投影随离墙的高度变长变虚。和旧的「贴纸科普」比，主体更大、画面有手作的质感，抽象概念落成一件实物（板子、便利贴、纸箱、吊牌）。横屏 16:9。

示例 `example/` 是《聊久了，AI 为什么会忘事》第 4 句「贴满了怎么办……它就看不见」，14.6 秒：板子贴满 → 剪刀剪掉最早两张 → 它们落进牛皮纸箱 → 镜头推到「我不吃香菜」、红圈圈出 → 被推远 → 拉远，小团子拿放大镜读板子 → 纸箱挂上「看不见」吊牌。新片从它复制开始。

## 画法要点（都在 `example/film/index.html` 的「画法」段）

- `deckleRect(key, w, h, r)`：毛边圆角矩形，按 key 固定随机，同一张纸每帧形状一样；`paperPiece()` 画纸片带投影。
- `shadowOn(ctx, lift)`：投影随 `lift`（0 贴墙 ~ 1 飞起）变长变虚。**Canvas 的 shadowBlur/Offset 不随变换缩放，要乘镜头缩放 `Z`**，否则推近时投影变薄。
- 纸纹：512 px 噪点 + 纤维贴图，最后在世界坐标里正片叠底一层（alpha 0.55），跟着镜头走；再加暗角。
- 图钉、剪刀、纸箱（后片 + 盖子在便利贴后，前片在前，落进去的只露上半截）、吊牌（摆动衰减）、红圈（描边逐渐画出）。
- 角色贴纸：直接 drawImage 加纸片投影，弹入 outBack + 转 -14°，常态轻微摇摆。文件名写在节拍表 `cast`（`what` / `read` / `huh`），放工程 `assets/xiaotuanzi/`；示例里留空，不出角色。

## 骨架（同一文件的「骨架」段）

- 节拍：只读 `film/cues.json`（有配音时 retime.py 生成），没有就读 `cues_base.json`。事件名见 `ev`。
- 便利贴运动 `notesAt(t)` 返回每张的位置、角度、缩放、`lift`、压扁 `sq`：贴上时从 1.35 倍砸下再压扁，撕下时先上挑再落、转着落地。
- 镜头 `CAM` 关键帧 + inOut 缓动、对数插值缩放；`camApply(ctx, c, par)` 的 `par < 1` 是视差层。贴满和被推远时镜头抖一下。

## 配乐

`example/film/audio.py`：mgaudio `lofi(flavor='boombap', keys='piano')`，90 bpm。音效全是纸：贴上 `sticker_slap` + `paper('rustle')`，剪 `scissors`，撕 `tape_rip` + `paper('flip')`，落箱 `paper('crumple')`，推远 `impact('thud')`，吊牌 `stamp('rubber')`。说话处压低 8 dB。

## 坑

- mg-styles-15 的样本库缺 `kalimba/MBira3_pluck_Main_D4…flac`，lofi 配方会报错；audio.py 开头把 kalimba 关掉，旋律改用 FM 合成。
- 便利贴落点别让箱子前片挡住关键字：「我不吃香菜」落在箱口上沿（y 598，箱子前片从 636 开始）。
- 剪刀要放大 1.7 倍才看得清；剪的时候留一道虚线切口。
- 渲染：`--mb 6 --workers 4`，14.6 秒约 8 分钟（Mac）。纸纹和投影比贴纸科普慢一些。

## 封面

`example/cover.py`：青墙 + 奶白毛边标题卡（前几行黑字，最后一行红色大字，下面一行小字）+ 贴满的软木板，黄色那张正在飞走。改文件顶部的 `TITLE` / `KEY` / `SUB`；账号名和角色读节拍表的 `brand`。
