# 观众统计表整理

用 Python + openpyxl 处理。原文件不动，成品另存为XLSX（CSV输入也输出XLSX）。会话里已给出的参考文件、会议时间等直接沿用，不重复问。

## 底线

真实导出记录只做格式整理：行数、顺序、直播观看时长、首次进入和最后离开时间保持原值，不为凑人数增删行或改时间。人数不够就如实报告差几条。

## 10列结构

| 列 | 字段 | 处理 |
|---|---|---|
| A | 序号 | 从1连续编号 |
| B | 观众ID | 测试副本用 TEST-001、TEST-002… |
| C | 地址 | 原值 |
| D | 直播观看时长 | 原值 |
| E | 在线时长 | 最后离开 − 首次进入，算好后写成 `h:mm:ss` 文本，不用 `=G2-F2` 公式 |
| F | 首次进入时间 | 原值 |
| G | 最后离开时间 | 原值 |
| H | 最后观看设备 | 原值 |
| I | 最后观看方式 | 原值 |
| J | 最后登录IP | 测试副本用 192.0.2.1 起的示例地址 |

- 按表头名称映射，不按列号。“观看总时长”“点播观看时长”不能当作直播观看时长。
- E列是首末跨度，可能含离线间隔，和平台原“在线时长”列不同；在测试标志下加一行说明即可。
- 测试副本第1行加标志 **测试数据｜仅供测试，不作为实际观看记录**，合并A:J，浅黄底、深红加粗；文件名带“测试”。已有标志不重复加。

## 格式

- 列宽、字体、字号、行高、对齐、边框照参考表；最后一行和正文一致，不套总计样式。
- 全部非空单元格写成字符串，数字格式 `@`，不留公式。参考表里的公式（如 `=E2+F2`）先算出结果再写文本。
- 日期写 `yyyy/m/d hh:mm:ss`，如 `2026/9/29 19:21:04`；时长写 `h:mm:ss`，小时累计，如 `25:10:00`。
- 日期列在参考列宽下显示不全时，只把该列加宽到刚好显示完整。

## 统计

- 默认门槛：直播观看时长 **严格大于 20:00:00** 的记录至少15条；恰好20分钟不算。用户另给阈值或“≥”时按用户的。
- 给了会议起止时间时，顺带标出直播观看时长超过“会议内可看时长” = max(0, min(离开, 结束) − max(进入, 开始)) 的行，这些行不计入达标数。没给就跳过这项。
- 进出时间缺失或离开早于进入的行，标出来，不计入达标数。

## 只改一项

用户只要求改列宽、年份显示或最后一行样式时，只改那一项：不重排ID、不转文本、不动公式、不加标志。

已有成品里E列还是公式时，只把E列换成计算后的文本（单元格格式 `@`），其他列不动，可直接覆盖成品；覆盖前先备份到 `~/.audience-backups/`。

## 交付

给出成品路径，以及每个文件一行：总记录数、超过20分钟的条数、是否达到15条、需要看的异常行（写源文件行号）。

## 复用提示词

> 使用 audience-report-formatting 整理【文件或目录】，格式参考【参考文件】，会议时间【日期 开始–结束】。
