# 项目目录和文档模板

## 目录结构

```
<项目>/
├── 交接.md          进度、下一步、用户偏好；换会话时先读
├── 1_文档/          需求.md、剧本定稿.md、连戏表.md、分段表.md
├── 2_素材/          角色/<名>_三视图.png、声音/<名>.wav、片尾/片尾卡.png
├── 3_提示词/        S1.txt … Sn.txt、分段.json、角色/（三视图提示词）
├── 4_生成片段/      <段>_t<序号>_<模型>_<分辨率>.mp4（run_segments.py 自动编号）
├── 5_审片/          检查图、审片报告、自审报告
├── 6_成片/          剪辑表.json、成片
├── 日志/            生成日志（run_segments.py 自动创建）
└── 归档/            按阶段收拢不再用的过程文件
```

一个项目是一集。用户做多部剧时，建议用一个总文件夹装所有剧，几部剧共用的东西放在总文件夹这一层：

```
<总文件夹>/
├── 工作台.json      可选设置，例如 {"入行日期": "2026-10-17"}；AI 视频工作台（独立项目 ai-video-workbench）读它显示入行天数
├── 短剧/<剧名>/第1集/   上面的项目目录，里面放一个 作品.json（类别 "短剧"、标题、成片），工作台据此列出作品
├── 代码动画/…          另一种做法的作品（opus-code-video 写代码做的动画）
└── 共用/参考视频/      用户保存的别人的片子和 <名>_拆解/（breakdown.py 输出），只在本机学习用
```

外层只放在用的东西。一轮做完后，废弃的候选、逐段审片图和日志先收进 `归档/<阶段>/`；用户确认过时的可以删除。用户在意文件夹整洁。

```markdown
# 需求：<片名>

| 项目 | 决定 | 来源 |
|---|---|---|
| 用途 | 练手 / 发布到 <平台> | 用户 |
| 题材 | | |
| 画风 | 写实真人 / 3D / 2D（拿不准时先出样图） | |
| 视频模型 | Seedance 2.5 | |
| 画质与画幅 | 480p（默认；用户点名再用 720p），9:16 | |
| 时长 | 约 N 秒正片 + 片尾卡 | |
| 单集预算 | ¥…（含重抽）；每次花钱前先报金额、等确认 | 用户 |
| 关键时刻 | 用户说"拍到这几下就满意"的 2～3 个瞬间，作为表演的验收标准 | 用户 |

| 字幕与 AI 标识 | 发布时按平台要求加 | |

```

## 剧本定稿.md

```markdown
# 剧本定稿：<片名>（vN，<日期> 用户确认）

相对上一版的改动：（逐条列出，改台词要注明用户已确认）

## 故事
（一段话讲完起因、冲突、反转、结尾钩子）

## 分段
| 段 | 时长 | 内容 | 台词 |
|---|---|---|---|

## 钩子和线索
- 下集钩子：……
- 本集埋的线索：在哪一段、以什么画面出现

## 事实核对
（专业内容的依据；写明"剧情纯属虚构"）
```

剧本自查清单：

结构
- 因果顺序对不对？（反例：开场就骂人，可对方还什么都没做）
- 前 3 秒有没有危机？
- 关键线索拍得出来吗？（"他出冷汗"，画面上要能看出来）
- 同一个信息有没有说两遍？（反例：揭晓结论时喊一遍，结尾点题又说一遍，对手吃瘪的反应也拍了两次）
- 结尾有没有余韵？"下集"钩子在本集有没有铺垫？

人物
- 每句台词有没有接收的人？主角每段在看谁？大部分时间都盯着对手，整片就成了对峙戏。
- 主角对要救、要帮的那个人，有没有至少一次关心的互动（问一句、扶一下）？台词全是冲着反派说的，主角就像专门来打脸的。
- 主角的行为符不符合职业常识？（反例：病人正被紧急推走，医生却停下来教训对手；真医生会跟着床走）
- 台词是不是全是判断句和命令句？全是的话，人物会显得端着，可以加一句问话或一个停顿。
- 身份落差说得通吗？（反例：实习医生对主任直接下命令太冲；客气但坚持更可信，反派的蛮横也更显眼）
- 剧本里给了选项的地方，最后是谁选的、选了哪个，台词里有没有说出来？（反例：医生给了"普通胃镜"和"无痛胃镜"两个选项，病人只说"那行，约吧"，医生就开了无痛，像替病人做了主；改成"那行，做无痛的，约吧"）

定稿前请用户找另一个模型或新开一个会话挑刺，意见收齐再定稿。

## 分段.json（run_segments.py 读取）

```json
{
 "S1": {"时长": 10, "图片": ["甲", "乙"], "音频": ["甲"]},
 "S2": {"时长": 8, "图片": ["乙"], "音频": ["乙"], "比例": "9:16"}
}
```

- "图片"按顺序对应提示词里的 @图片1、@图片2…，文件取 `2_素材/角色/<名>_三视图.png`。
- "音频"按顺序对应 @音频1…，文件取 `2_素材/声音/<名>.wav`。
- 运行：`python3 scripts/run_segments.py --project <项目目录> S1 S4`（不写段号就跑全部；`--model 2.5|mini|2.0`，`--res` 默认 480p）。
