# 百度网盘

优先使用当前会话已连接的百度网盘 MCP。先查看实际工具说明和参数 schema，再调用；服务端能力可能变化，不凭工具名猜参数。

## 当前会话没有 MCP 时

使用本技能的 `scripts/netdisk_mcp.py`，通过官方 MCP Python SDK 直接连接现有 SSE 服务。它只读取配置，不修改任何客户端设置。需要 Python 3.10+ 和 `mcp`；推荐用支持脚本依赖的 `uv run`：

```bash
# 将 SKILL_DIR 设置为本次读取的 SKILL.md 所在目录。
uv run "$SKILL_DIR/scripts/netdisk_mcp.py" config
uv run "$SKILL_DIR/scripts/netdisk_mcp.py" tools
```

配置选择顺序为 `~/.workbuddy/mcp.json`、`~/.codebuddy/.mcp.json` 中已启用的 `baidu-netdisk`。`config` 只做离线检查；`tools` 才验证连接并返回真实 schema。需要指定客户端时，在子命令前加 `--config <配置文件路径>`。默认配置一旦选定，认证失败不自动换到另一个账号。

调用时，把按照真实 schema 组装的参数写到仓库外的私有 JSON 文件，或通过标准输入传入：

```bash
uv run "$SKILL_DIR/scripts/netdisk_mcp.py" call '<实际工具名>' --args-file /private/path/arguments.json
# 也可使用 --args-file - 从标准输入读取 JSON 对象。
```

已安装 `mcp` 的 Python 环境可以直接运行脚本。脚本默认总超时 45 秒，可用 `--timeout` 调整；超时或响应不确定时，先查看目标状态，不盲目重复写操作。工具输出属于用户私有数据，不保存到技能仓库。

网络操作遵循当前机器的网络规则；本机如有 `~/.ai-global/PROXY_NETWORK.md`，先读取。默认使用现有系统路由，不注入代理；连接失败时再按该文件处理。

## 选择操作

- 查看目录或文件类型：使用通用列表或文档、图片、视频分类列表，保留分页信息。
- 已知文件名关键词：优先文件名搜索。自然语言描述主题、画面或内容：选择语义检索；正文或图片文字：选择文档内容或 OCR 来源。按需限制目录、类型、扩展名和结果数。
- 查看文件详情：从列表或搜索取得真实文件 ID，再请求元信息；现有连接器单次最多 10 个 ID。容量和账号信息使用对应查询工具。
- 新建、复制、移动、重命名：先定位源对象，明确目标目录、名称和冲突策略。用户未授权覆盖时，选择跳过、失败或生成副本名；整理请求已经明确授权的操作无需反复确认。
- 分享：按用户要求设置文件、有效期和提取码。现有连接器提取码为 4 位数字或小写字母；返回链接、有效期和提取码，只有另有发送授权和可用渠道时才发送给他人。
- 保存文字：使用文本保存接口，现有上限为单次 2 万字。未指定目录时可采用工具默认的 `/来自：mcp_server` 并说明位置；按内容选择合理文件名，遵循真实工具的格式说明。
- URL 转存：要求可直接下载的地址。需要登录、验证码或临时授权的网页地址不保证可用。

写操作必须属于用户请求范围；仅查找文件不授权顺带整理、保存或分享。影响源文件、覆盖同名内容、分享敏感资料时，如目标或范围仍有实质歧义才询问。网盘路径一般以 `/` 开头；是否编码中文由实际参数说明决定，避免重复编码。

## 能力边界与失败处理

截至本技能整理时，现有连接器没有云端文件下载到本地、任意本地二进制上传或删除接口。文本保存和 URL 转存不等于通用文件上传。若实时 schema 新增能力，以实际工具和用户授权为准。本地同步目录的内容不能证明云端文件已存在或同步完成。

认证失败（401/403、token 失效；百度服务也可能返回 HTTP 400 和 `auth fail:token fail`）时，在选定配置所属的客户端重新连接百度网盘，再重试只读查询。不要把另一客户端的 token 静默替换过来。路径不存在时重新浏览父目录；搜索无结果时放宽来源或筛选，或退回文件名搜索；遇到同名冲突沿用用户指定策略。

访问令牌只从本机私有配置读取。不得把完整 SSE URL、token、Cookie、账号响应或运行参数加入仓库、对话、日志或命令行参数。连接器说明曾使用“上传”作为概括，实际能力应以 `tools` 返回的 schema 为准。
