# 外观修复与宽屏重排

## 先诊断再处理

每页至少检查四角、底边、标题、正文和图表边缘。在私有清单记录：页码、问题位置、问题类型、是否覆盖内容、拟采用的方法、是否已重新渲染确认。源 PPT 可能已经加过遮盖层，检查当前可见画面和对象结构，不能只取第一张图片就认为它是成品。

常见问题与方法：

| 看到的问题 | 优先处理 | 不能接受的结果 |
|---|---|---|
| 课件外会议背景、摄像头、黑边 | 精确裁到课件边界 | 把正文、页码、脚注一起裁掉 |
| 左下角/底部“正在共享” | 同页换帧；纯空白处可原生无边框同色遮盖 | 灰底上留白块、渐变上留色块、压掉正文 |
| 右上角会议计时器 | 检查整段变化范围，换帧或局部重排 | 套一个固定框到所有页，删掉标题/角标 |
| 鼠标指针、激光点 | 同页选另一个时间的帧 | 抹掉其下方的数字、曲线或笔画 |
| 悬浮控制条/弹窗 | 找消失后的稳定帧 | 填补被遮住的医学信息 |
| 旧装饰边框或模板混乱 | 用户授权重排时去除旧模板，统一新排版 | 只盖局部，留下残线和拼贴边 |
| 纯文字模糊 | OCR 辅助并对照原图，重建原生文本 | OCR 未校对就成稿、整页重新截图导致仍不可编辑 |
| 图表/报告模糊 | 找原图或更清晰帧，保真裁切、合理显示 | 猜测数据重画、生成假的检验结果 |

处理顺序是“换帧 → 裁课件外界面 → 仅空白区小范围同色遮盖 → 内容重排”。这是方法选择，不要求每页都经过所有步骤。简单空白区遮盖可直接完成；用户已经授权整套重排时不要反复让用户选择。

## 共享提示与时钟的边界

共享提示有时连接黑色侧边与课件白底，导致自动边界检测把黑边也算进课件。用多行边缘位置、首中尾对照检查，不直接用最大白色连通域作为最终裁切。

右上角计时器可能随布局变大、换位置或换背景。按页/同布局区间量框，保留其邻近标题、Logo、页码和真实日期。检验报告的申请时间、报告时间，CT 的检查时间，图表横轴日期是内容，不是待清理的会议时钟。

原生遮盖仅用于空白区，坐标要转换正确。设截图放到 PPT 上的左上角为 `(ox,oy)`，显示大小为 `(W,H)`；无 crop 的图内 `(x,y,w,h)` 像素区，在 PPT 对应 `(ox+x/iw*W, oy+y/ih*H, w/iw*W, h/ih*H)`。有 crop 时要先减掉裁切原点并改用裁切后宽高，不能继续按整帧比例套框。无描边，不默认加圆角/阴影；颜色从相邻未遮挡的同背景区域确定并检查。

**遮盖不是内容擦除。** 底层原图仍可能留在 PPT 包内，用户取消裁切/移开形状后可看到。如果要求永久移除某内容，需要按宿主允许的图片编辑工具生成实际清理后的图，再替换并检查未被引用的旧媒体；不要把视觉遮盖说成隐私脱敏或文件内部彻底删除。本任务通常只是展示外观整理，不能自行扩大成永久清除全部来源。

## 重建可编辑文字

先分类：纯文字、文字＋影像、报告/表格、图表、文献截页、封面/过渡。把 OCR 用作输入草稿，逐项核对并形成一份人工修正后的内容清单，包含：标题、段落、图片裁切、引用、无法确认项。后续排版只读这份清单，不能重新跑旧转录脚本覆盖修正。

校对重点：

- `0/O`、`1/l`、中文相近字、小数点、负号、百分号、`×10⁶/L`、上下标、剂量与频次。
- 数值和单位尽量整体换行，如 `2.71 mmol/L`；括号和 `（+）/（−）/（++）` 不拆开。
- 表头、行列、图例、坐标轴、参考线、页脚参考文献都属于内容；不能因为小而省掉。
- 原文剂量冲突或出现两个并列数值：保留可辨认原文，单独列待核对事项，不擅自选一个。
- 文献截图从半句开始：优先找同页其他帧、相邻页面或可核实原文补齐；没有证据时不要凭常识补成建议。可保留原图/明确省略号并单独说明缺失。
- 新增的标题应概括已有内容，不能新增疗效结论。来源中的“我们经验”等不能变成作者无关的普遍事实。

没有必要把医学报告中的细小字逐个变成原生表格；保持真实报告图像通常更可靠。用户要求图表可编辑时，只有读得清的完整数值或源数据才能重建；否则明确说明还缺什么，先完成其余页面。

## 4:3 → 16:9

完整操作顺序、坐标换算及与图片课件换底板的共用步骤，见 [16:9 重排与图片课件换底板](widescreen-and-background.md)。

先检查 PPT 画布和真正课件图的比例，两者可能不同。确定内容本身是 4:3，还是视频把 16:9 课件放进了带黑边的区域。

| 方法 | 使用条件 | 结果 |
|---|---|---|
| 等比放入 16:9 画布 | 用户只需宽屏容器、允许两侧留白 | 内容完整但版面不会自动变宽 |
| 按内容重新排版 | 要像正常宽屏课件、清理视频感 | 推荐，原生文字＋按比例证据图 |
| 横向拉伸或大幅裁上下 | 不采用 | 字体变扁、影像变形或丢信息 |

进行重排时：

1. 用户只要求研究，先选封面、文字页、混合证据页 2–3 页验证方案；用户已批准完整制作，继续完成同方向的全部页面。
2. 选择适合原讲课风格的字体和颜色。先检查实际字体可用性，确认中文、希腊字母、上下标均能显示。不要把某台电脑上的字体写成永久依赖。
3. 纯文字页用清晰的层级和留白；文字＋影像页左右排；长报告和图表尽量增加有效显示面积，不把整个旧背景一并嵌入。
4. 按[选页与去重规则](page-selection-and-dedup.md)确定同页渐进内容的代表状态，重排遵从已确认清单；不得仅为了版式整齐改变用户要求的页数。
5. 先确定固定画布，再用 `scale=min(availableWidth/cropWidth,availableHeight/cropHeight)` 放置图片。原生裁切比例分别按整帧宽高计算。图像比例与裁切框一致；改画布不等于改图片比例。
6. 引用、作者和来源放到适当位置并保证可读；正文密度高时先调结构，不盲目缩成小字。
7. 每页渲染复核。常见收尾问题是标题最后一字落单、正文末尾“物。”孤行、`（+）`拆开、图表裁掉年份、旧背景从边缘露出、CT 拉伸。

影像和数据图的保真优先于完全填满版面。来源图本身缺失的标签不能猜补；不能保证低清来源变成高清原件。

## 备注和标题

新建的提取稿备注默认空；日志记录在工作文件中。如果现有 PPT 备注全是提取过程，可按用户要求清理。存在真实讲稿时先识别范围，只去掉不属于课件的过程内容，不能无差别删除。

命名标题要看封面、主病例和总结。例如没有封面的病例分享可命名为“一例……的诊治”，具体病原、部位、严重程度必须有材料支持。正式标题/讲者以原资料为准，不把文件名里的日期误当课件标题。
