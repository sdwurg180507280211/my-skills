# 提示词：官方写法与实测经验

## 官方写法（Seedance 2.5）

- 参考素材写成 `@图片1`、`@音频1`…，编号和请求里同类素材的顺序一致。每份素材都要说清楚：**它提供什么、不采用什么**。
- 声音用符号区分：**台词用 `{}`**，音效用 `<>`，音乐用 `()`，字幕用 `【】`。中文以外的台词，要在前面注明语言。
- 顺序：主体 + 动作/事件 + 场景与环境 + 视觉风格 + 运镜/切镜 + 声音，不需要的部分可以省略。
- 实测：台词改放进 `{}` 后，2.5 生成的 9 条都没有再自己往画面上打字幕。之前用中文引号写台词时，Mini 会把读诊断结论这类台词打成字幕，还是错字。
- 官方还提供了一个提示词优化工具（`sd25-pe`），属于第三方 Skill，要不要装由用户决定。

## 分段提示词模板

```
写实电影质感：皮肤哑光、看得见自然毛孔，不磨皮、不油光，人物脸上没有反光。甲的脸始终干爽、哑光。
@图片1 是甲的角色设定图（同一个人的三个角度），只提供他的长相（左耳垂下方有一颗黑痣）、发型和服装（……，胸前没有工牌和笔），不采用设定图的灰色背景和并排构图。
@图片2 是乙的角色设定图……
@音频1 只提供甲的音色，不采用它的语气、节奏和台词内容。
场景：<地点>，<时间>。房间没有窗户，没有<容易被加进来的东西>；<光源>；<固定陈设>，<会显示文字的设备>始终在背景深处、处于焦外虚化，屏幕上看不清任何数字。<站位和朝向>。
风格：35mm 镜头，<调色>，浅景深。
[0-3秒] 近景，<谁>在<哪>，<看着谁、在做什么>，<情绪怎么变、呼吸或细微动作>，说：{台词}说话时嘴唇明显开合。<运镜>。
[3-6.5秒] 过肩镜头，从乙的肩后拍甲……
声音：<环境音>贯穿始终，以及人物台词。
全片没有背景音乐。无字幕、无文字叠加；屏幕、单据、排名表上剧情要看清的字一律不让模型写（后期合成），背景里的杂字不强求。参考图里没有的东西一律不要添加。
```

- **只挂这一段出场的人物**的设定图，只给**说话的人物**配音色参考。
- 质感要求放在开头；"参考图里没有的东西一律不要添加"放在结尾，用来防止模型给角色凭空加眼镜、首饰、工牌。
- 场景里要**写明没有什么**（没有窗户、没有手术无影灯……）。不写的话，同一个地点在不同段里会长得不一样。
- 镜头写成 `[起-止秒] 景别，动作，带表演状态的台词`。镜头数按时长来定：一段 2～4 个，每个镜头至少 2 秒。

## 写什么，出什么（实测反例）

- **人物的固定姿态和位置写进公共部分，每段都带上**（"医生全程坐在办公桌后，不站起来"）。只在个别段落写，或者只写镜头从哪拍，模型会为了构图让人站起来、换位置：实测有两段医生站到病人身边问诊，前后段又是坐着，一看就不连戏，也显得居高临下。
- **每段写明"画面里只有谁"**，道具写明属于谁（"白色塑料袋只属于妻子"）。公共设定里列了所有人物和道具时，模型会把人塞进不该出现的画面、把道具串到别人手上；分镜预览里改成白名单写法后，重画的几张都对了。
- **镜头位置决定屏幕朝向**：写"从医生身后拍"，桌上显示器的屏幕自然会朝着镜头；要只露黑色背壳，就从病人这一侧拍。
- **说话的人一切过来就开口**：写成"医生从电脑前转过身来，说……"，模型会先演完转身再开口，台词被挤到段尾。改成"医生已经侧身对着她，镜头一切过来就开口"。
- 要一个小诊室，就写"十几平米、只有一张检查床、没有别的床和输液架"；只写"诊室"，模型容易画成摆着一排床的大病房。

| 写法 | 实际效果 | 改法 |
|---|---|---|
| 通用结尾写"胸牌是空白的" | 本来没胸牌的角色也长出了工牌 | 只写在需要的角色身上；其他人写"胸前没有工牌和笔" |
| "眯着眼斜睨" | 演成了笑眯眯，像开心的笑 | 写"眼皮半垂、居高临下、一边嘴角上扯、不露牙齿" |
| 同一句里写"冷笑"和"说台词" | Mini 保留冷笑，嘴几乎不动，台词成了画外音 | 说话的镜头写"嘴唇明显开合"，不要再叠闭嘴的表情 |
| "额头冒汗""汗珠" | 皮肤发亮；2.5 会画出很真实、带反光的汗珠 | 剧情需要时就保留（例如"出冷汗"是关键证据）；不需要时用领口汗湿、鬓角打湿来表现 |
| 没写汗，但情绪紧张 | 2.5 自己给角色加了汗 | 写正面描述"脸始终干爽、哑光"，不要写"没有汗"，免得把"汗"这个词带进去 |
| 三视图提示词里写"脸色发白" | 嘴边被画上一圈白色色块 | 写"面色灰暗、嘴唇发干"这类不会被直接画成颜色的描述 |
| "目视前方、不回头"地说台词 | 像对着空气念台词，很尴尬 | 台词要有接收的人：侧头对着某人说，再接对方的反应镜头 |
| 只写"监护仪数字模糊不清" | 设备离人近时，读数清清楚楚 | "始终在背景深处、处于焦外虚化，屏幕上看不清任何数字" |
| 单人近景写"看向画面左侧的某人" | 有时视线方向会反 | 改用过肩镜头，把听话人的肩膀拍进前景 |
| 主角每段都写"盯着""直视""皱眉""一字一顿""声音很硬" | 整片女主都在瞪人、和人对峙，用户说"像要杀人一样，太正式了"；"大声、果断地喊"演成了龇牙、脖子青筋绷起 | 写看谁、要做什么、情绪怎么变，见下面"表演与台词"（对照实验验证过：只改写法，同一段就从吼人变成了焦急地喊人） |
| 三视图提示词写"眼神冷静坚定""神情傲慢" | 设定图本身就是冷脸、立正。对照实验（同一提示词、同一 seed，只换参考图）：冷脸三视图配新写法照样不凶；换成中性三视图，表情差别不大，脸却换了 | 表演靠写法。新项目的三视图用中性表情；已经开拍的项目不要为了表情换图 |
| 只写人物站在床尾说台词，没给动作 | 人物立正站着念台词，像证件照 | 给一个具体动作：扶着床栏、低头看病人、转身喊人。对照实验里加了动作，就不再立正 |
| 只写"刚看完心电图结果" | 模型给她塞了一张 A4 报告，和前一段机器打出的窄纸条对不上 | 道具写清形状和来历，例如"手里捏着一段刚从机器里打出来的窄心电图纸条" |

## 表演与台词

- 每句台词前面写清楚这一刻的**表演状态**，语气靠它控制，音色参考只管音色。表演状态写四件事：**看谁、要做什么、情绪怎么变、呼吸和细微动作**。例如："她先低头看病人的脸和手，眉头轻轻一蹙，吸一口气，抬眼对主任语速稍快地说：{……}说完马上转回病人身边。"
- 每个镜头给人物一个具体动作（扶床栏、低头看病人、转身喊人）。没有动作时，人物容易立正站着念台词。
- 只写形容词（"冷静""笃定""很硬""大声、果断"）时，会被放大着演。主角尤其要注意：盯着、直视、皱眉、一字一顿、毫不退让，单看每个词都合理，每段都用，整片就成了瞪人和对峙。
- 主角的情绪要有落点：关心落在要救、要帮的人身上；面对反派沉得住气就够了，不用比他更凶。反派可以傲慢，也要写清楚他此刻想干什么（敷衍、催人走、找台阶下）。
- 用户看片时的原话（例如"像杀人"）不要写进提示词，改写成想要的正面表演。
- 对话用**过肩镜头**（从听话人肩后拍说话人）：视线、对象、站位都很清楚，实测效果最稳。
- 每段结尾，给台词留 0.3 秒以上的余量，避免话说到一半就被截断。

## 大动作

- 推床、打斗、摔倒这类大动作**单独成一段**，给 4～5 秒以上，用固定镜头；容易崩的部位（手、腿）尽量不进画。
- **写清楚数量和归属**。实测反例：参考图里的病人被放在前景一张不动的床上，护士推走的是另一张空床；Mini 还出现过病人长两个头。改成"整个画面只有一张床；病人就躺在被推走的床上、和床一起移动；前景和背景都没有别的床；人体结构正常，不要出现多余的头、手或脚"，重做一次就过了。
- 想在大动作里埋线索（例如东西掉落）时，写明物件的样子，要和后面的特写对得上。

## 三视图提示词

```
角色设定图（character sheet），写实电影摄影风格。同一个人在同一张横向画面里出现三次，从左到右依次是：
胸像特写（正面）、全身正面站姿、全身侧面站姿（面朝画面左侧）。三个角度是同一个人，长相、发型、服装完全一致。
人物：<年龄、性别、脸型、发型、一个辨识特征（痣、疤、补丁）、服装（写到鞋）、"没有"的东西>。
表情放松、中性，嘴角自然，眼神平和；全身是放松的自然站姿，肩膀放松，重心略偏一条腿。
纯浅灰色影棚背景，柔和均匀的布光。皮肤哑光、看得见自然毛孔，不要磨皮，不要油光。画面中不出现任何文字、标注、箭头或比例尺。
```

- 三视图只管长相和服装，**不写性格和情绪**（"眼神冷静坚定""神情傲慢""咬着牙忍痛"）。性格写进连戏表的人物基调，情绪写进每段提示词。实测冷脸三视图对视频表演的影响比提示词小得多，所以已经开拍的项目不要为了表情换三视图：换图就是换脸，前后段对不上。
- 用 `seedream.py --size 2048x1152` 生成。生成后先放大检查脸，有问题就改提示词重做（约 0.3 元一张）。
- 辨识特征以生成出来的图为准，连戏表照图写。比如提示词写"右眉尾的痣"，图上画在了左眉上方，连戏表就写左眉上方。
- 实测：整张三视图作为参考图，8 段里人脸都一致，辨识特征也都出现了。

## 音色参考

- 每个说话的角色一段：从用户认可的片段里截一段干净的台词，2～6 秒，做降噪和响度统一（`highpass=f=80,lowpass=f=9000,loudnorm=I=-18`），存成 wav。
- 提示词里写"@音频N 只提供某某的音色，不采用它的语气、节奏和台词内容"。
- 实测：锁音色前，同一角色在两段之间的基频差约 20%；锁定后，男声 116 Hz 对 122 Hz，女声 221 Hz 对 219 Hz。

## 模型选择

- 默认用 2.5 的 480p；用户点名要更高画质，再出 720p。Mini 适合快速验证结构和节奏，但细微表情（轻蔑、不屑）演不出来，皮肤也容易有油光。
- 表演吃重的段落（细微表情、情绪转折）一定用 2.5。
